# ห้องเรียน Climate Change 282221

เว็บช่วยสอนรายวิชา 282221 การจัดการพลังงานและสิ่งแวดล้อมเบื้องต้น สัปดาห์ที่ 7 การเปลี่ยนแปลงสภาพภูมิอากาศ มี 6 ขั้นตอน ได้แก่ สุ่มจัดกลุ่ม สไลด์บรรยาย อภิปรายกลุ่ม นำเสนอและซักถามสด บัตรออกรายกลุ่ม และส่งการบ้าน

หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลและไฟล์เก็บใน Google Drive ของอาจารย์ผ่าน Google Apps Script รายชื่อนิสิตอยู่ใน Google Sheet เท่านั้น ไม่อยู่ในโค้ดของ repository นี้

## ตั้งค่าครั้งแรก

### 1. ติดตั้งระบบหลังบ้าน (Google Apps Script)

1. เปิด https://script.google.com ด้วยบัญชี teerachai4@gmail.com แล้วกด **New project** ตั้งชื่อ `climate-class-282221`
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs`
3. ในฟังก์ชัน `setup()` แก้ข้อความ `ใส่รหัสอาจารย์ที่นี่` เป็นรหัสผ่านโหมดอาจารย์ที่ต้องการ
4. เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **Run** และกดอนุญาตสิทธิ์ Google Drive และ Google Sheets (ถ้าขึ้นว่า "Google hasn’t verified this app" ให้กด Advanced แล้วกด Go to climate-class-282221)
5. เมื่อรันสำเร็จ แก้รหัสใน `setup()` กลับเป็น `ใส่รหัสอาจารย์ที่นี่` ได้เลย รหัสจริงถูกเก็บใน Script Properties แล้ว
6. กด **Deploy → New deployment** เลือกประเภท **Web app** ตั้ง *Execute as* = **Me** และ *Who has access* = **Anyone** แล้วกด **Deploy**
7. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 2. ใส่ URL ลงในเว็บ

แก้ไฟล์ `config.js` ใส่ URL ที่ได้ใน `apiUrl` แล้ว commit

### 3. เปิด GitHub Pages

ใน repository ไปที่ **Settings → Pages** เลือก *Source* = **Deploy from a branch**, *Branch* = **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save** รอราว 1 นาที เว็บจะอยู่ที่

https://smalltee2.github.io/climate-class-282221/

## การใช้งาน

- **นิสิต:** เปิดลิงก์เว็บได้เลย ไม่ต้องมีบัญชี ส่งงานกลุ่มด้วยการเลือกหมายเลขกลุ่ม และส่งการบ้านด้วยรหัสนิสิต 8 หลัก
- **อาจารย์:** กดปุ่ม **โหมดอาจารย์** มุมขวาบนแล้วใส่รหัส จะเห็นชื่อเต็ม รหัสนิสิต ปุ่มสุ่ม นาฬิกาจับเวลา การให้คะแนนบัตรออก และรายการส่งการบ้านทั้งหมด
- ในโหมดนิสิต ชื่อจะแสดงเป็นชื่อต้นและอักษรแรกของนามสกุลเท่านั้น

## แก้โค้ดหลังบ้านภายหลัง

หลังแก้ `Code.gs` ใน Apps Script ให้ไปที่ **Deploy → Manage deployments** กดไอคอนดินสอ เลือก *Version* = **New version** แล้วกด **Deploy** URL เดิมจะใช้ต่อได้
